Protocolo HTTP

O HTTP (HyperText Transfer Protocol) e um protocolo de comunicação que permite a transferência de informações entre clientes (como navegadores) e servidores na World Wide Web. Ele define como as mensagens são formatadas e transmitidas, bem como as ações que os servidores e navegadores devem tomar em resposta a diferentes comandos.

1. Papel do HTTP na comunicação entre navegador e servidor

O HTTP atua como a linguagem padrão que permite que o navegador (cliente) solicite recursos (como páginas e imagens) e que o servidor web responda a esses pedidos entregando os conteúdos solicitados. Ele funciona através do modelo clássico de cliente-servidor.

2. Conceitos Fundamentais: Cliente, Servidor, Requisição e Resposta

  • Cliente: O software que faz solicitações ao servidor, como um navegador web.
  • Servidor: O computador que recebe as solicitações do cliente e fornece os recursos solicitados.
  • Requisição: A mensagem enviada pelo cliente ao servidor para solicitar um recurso.
  • Resposta: A mensagem enviada pelo servidor ao cliente em resposta à requisição.

3. Métodos HTTP: GET & POST

Os métodos HTTP idiccam a ação desejada a ser executada no recurso solicitado:

  • GET: Solicita a recuperação de um recurso. É usado para obter dados do servidor sem alterar seu estado.
  • POST: Envia dados ao servidor, geralmente para criar ou atualizar recursos. Pode alterar o estado do servidor.

4. Exemplo de uma requisição HTTP

Abaixo encontra-se um exemplo textual de uma requisição HTTP do tipo GET:

GET /index.html HTTP/1.1
Host: www.exemplo.ifsc.edu.br
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64)
Accept: text/html,application/xhtml+xml

5. Exemplo de Resposta HTTP

Abaixo esttá um exemplo a resposta correspondente enviada pelo servidor, contendo o código de status de sucesso e o conteúdo HTML:

HTTP/1.1 200 OK
Date: Mon, 01 Nov 2026 12:00:00 GMT
Content-Type: text/html; charset=UTF-8
Content-Length: 1234

<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <title>Página de Exemplo</title>
</head>
<body>
    <h1>Bem-vindo ao IFSC!</h1>
    <p>Esta é uma página de exemplo servida via HTTP.</p>
</body>
</html>

6. Códigos de Status HTTP

Os códigos de status informam o resultado de uma requisição. Dividem-se em várias categorias (sucessos, redirecionamentos, erros do cliente e erros do servidor).

  • 200 OK: A requisição foi bem-sucedida e o recurso solicitado foi entregue.
  • 301 Moved Permanently: O recurso solicitado foi movido permanentemente para um novo URL.
  • 400 Bad Request: A requisição não pôde ser entendida pelo servidor devido a sintaxe inválida.
  • 401 Unauthorized: A requisição requer autenticação do usuário.
  • 403 Forbidden: O servidor entendeu a requisição, mas se recusa a autorizá-la.
  • 404 Not Found: O recurso solicitado não foi encontrado no servidor.
  • 500 Internal Server Error: Ocorreu um erro no servidor ao processar a requisição.
